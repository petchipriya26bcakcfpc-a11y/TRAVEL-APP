# TRAVEL-APP

# Project Overview

The Travel App is a user-friendly mobile application designed to help users explore destinations and book flights, hotels, buses, and other travel services in one place.

# Objective

1.To make travel planning simple and convenient.
2.To help users discover popular destinations.
3.To provide an easy and quick booking experience.
4.To display complete trip and booking details.

# Features
1.Search for destinations, hotels and flights
2. Popular destination recommendations
3. Flight booking
4. Hotel booking
